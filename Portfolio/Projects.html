Project 2: Collection of Notes

A collection of my notes for courses I have taken over the years to jot my thoughts down and fast references. This will be further expanded on to hold other materials and past year papers

GitHub pages

This was not really a large project even though I spent a lot of my time on it. I sometimes write my notes in Obsidian, a note taking app done on Makrdown, this was helpful for a lot of my courses since I can format the way I write text and write equations in latex which was useful for math intesnive classes. I used MkDocs as a tool to convert Markdown files into a static website that can be hosted on GitHub pages. This was a good experience to learn about static site generators and how they work.
